# Selected references for RANOpt AI multi-cell slicing

These papers were selected specifically for the planned extension of RANOpt AI v17.7: variable cells per cluster, per-slice capacity/coverage, SLA-aware control, inter-cell coordination, and O-RAN deployment.

1. T. Hu, Q. Liao, Q. Liu, D. Wellington, and G. Carle, “Inter-Cell Slicing Resource Partitioning via Coordinated Multi-Agent Deep Reinforcement Learning,” 2022. <https://arxiv.org/abs/2202.12833>
   - Primary reference for coordinated inter-cell slicing and multi-agent control.

2. R. Li et al., “Deep Reinforcement Learning for Resource Management in Network Slicing,” *IEEE Access*, 2018. <https://arxiv.org/abs/1805.06591>
   - Foundation for demand-aware DRL radio-resource slicing and state/action/reward design.

3. Y. Liu, J. Ding, Z.-L. Zhang, and X. Liu, “CLARA: A Constrained Reinforcement Learning Based Resource Allocation Framework for Network Slicing,” 2021. <https://arxiv.org/abs/2111.08397>
   - Reference for SLA constraints and constrained-MDP resource allocation.

4. H. Cheng et al., “ORANSlice: An Open-Source 5G Network Slicing Platform for O-RAN,” 2024. <https://arxiv.org/abs/2410.12978>
   - Implementation reference for mapping slice control to O-RAN components.

5. S. A. Hashemian and F. Ashtiani, “Analytical Modeling and Improvement of Interference-Coupled RAN Slicing,” 2022. <https://arxiv.org/abs/2208.07045>
   - Reference for interference-aware multi-cell RAN slicing.
